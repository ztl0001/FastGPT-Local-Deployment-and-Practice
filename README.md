# FastGPT 本地部署与实战

本仓库整理了一套面向新手的 FastGPT 本地部署与实战教程，并配套一个「智能投顾助手」示例项目。内容涵盖 Windows 11 环境下的 Docker 部署、模型与知识库配置、工作流搭建，以及投资基础知识材料。

## 仓库内容

| 文件 | 说明 |
| --- | --- |
| [FastGPT部署教学文档.md](FastGPT部署教学文档.md) | Windows 本地部署 FastGPT 的完整教程，包含 Docker Desktop、WSL2、docker-compose、启动、排错与模型接入。 |
| [智能投顾助手搭建教程.md](智能投顾助手搭建教程.md) | 在已部署 FastGPT 的基础上搭建「智能投顾助手」的实战教程，包含模型配置、金融知识库、工作流分支、调试与分享。 |
| [投资基础知识文档.md](投资基础知识文档.md) | 智能投顾助手配套的金融知识库材料，覆盖基础概念、投资理论、风险控制与案例分析。 |

## 推荐阅读顺序

1. 先阅读 [FastGPT部署教学文档.md](FastGPT部署教学文档.md)，完成本地 FastGPT 部署。
2. 使用 [投资基础知识文档.md](投资基础知识文档.md) 创建并导入金融投资知识库。
3. 按照 [智能投顾助手搭建教程.md](智能投顾助手搭建教程.md) 配置模型、搭建工作流并调试。

## 快速概览

- 环境基线：Windows 11、Docker Desktop、WSL2。
- FastGPT 版本：v4.17.0。
- 部署方式：docker-compose。
- 模型网关：aiproxy。
- 知识库：PostgreSQL / pgvector。
- 索引模型示例：`BAAI/bge-m3`。
- 示例应用：智能投顾助手。

## 核心流程

```text
用户访问
  → FastGPT 工作流
    → 问题分类
      → 金融知识咨询：知识库检索 + AI 对话
      → 市场查询：MCP 工具调用
      → 投资诊断：风险评估问卷 + AI 分析报告
      → 其他内容：通用对话
```

## 注意事项

- 部署前请确认 Docker Desktop 正常运行，并保证本机有足够内存和磁盘空间。
- 配置模型渠道时，OpenAI 兼容接口的 Base URL 通常需要以 `/v1` 结尾。
- 配置知识库前，需要确保已配置可用的 Embedding 模型。
- 文档中的投资相关内容仅用于学习和教学演示，不构成投资建议。
